# 分辨率助手

Windows 10/11 x64 单文件桌面工具。通过预设按钮、系统托盘菜单或全局快捷键，直接调用 Windows API 切换主显示器的分辨率和刷新率，不依赖 BAT 或 QRes。

## 使用

运行 `分辨率助手.exe`（构建输出名为 `ResolutionAssistant.exe`，可以重命名）。

- 主窗口：点击预设卡片立即尝试切换；顶部显示当前模式。
- 设置与预设：添加、编辑、删除、上移和下移预设，最后点击“保存设置”。取消不会应用修改。
- 自定义：名称、宽度、高度、刷新率和独立全局快捷键。数值允许 `0` 至 `4294967295` 的整数；不会根据显卡支持列表或宽高比限制保存。
- 快捷键：选择主键及 Ctrl / Alt / Shift / Win 修饰键；选择“未设置”取消绑定。重复或被其他程序占用的快捷键会阻止本次设置保存，并保留/恢复原快捷键。F12 为 Windows 调试保留键，不能注册。
- 开机自启：在设置中勾选“开机后在托盘启动”并保存。默认关闭，不需要管理员权限。启用后请保持 EXE 路径不变；移动后需重新启用并保存以更新启动路径。
- 常驻：点击窗口关闭按钮隐藏到托盘；托盘菜单可切换、打开设置或退出。再次运行 EXE 会唤起已有实例。

首次运行提供 `2560×1440 / 240 Hz`、`2048×1536 / 240 Hz`、`1920×1440 / 240 Hz` 三个预设，均默认不绑定快捷键。删除全部预设后，下次启动仍保留空列表。

## 显示切换边界

仅操作 Windows 主显示器，不提供显示器选择。直接提交用户输入的模式，不预先测试硬件支持、不自动降低刷新率、不自动回退。系统拒绝时显示错误，预设仍保留。

不兼容的显示模式可能导致画面异常或黑屏，且软件不提供超时恢复。请先了解通过 Windows 显示设置恢复的方法。4:3 的拉伸/黑边由显卡和显示器缩放设置决定。

切换只影响当前会话，不写入显示模式注册表；退出本软件不会主动恢复原分辨率。

## 数据与启动项

配置自动保存至 `%LOCALAPPDATA%\ResolutionAssistant\settings.json`，包含预设与快捷键；单 EXE 分发不需要携带配置文件。配置采用同目录临时文件写入并替换；损坏配置不会被默认值静默覆盖，启动时将显示配置位置及错误。

开机自启使用当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `ResolutionAssistant` 项，命令为带引号的 EXE 路径加 `--background`。取消勾选并保存即可删除该项。

## 构建

需要 .NET 10 SDK 与网络连接以还原官方运行时包。在项目目录运行：

```powershell
dotnet publish ResolutionAssistant.csproj -c Release -o artifacts/publish
```

生成 `artifacts/publish/ResolutionAssistant.exe`。Windows x64 自包含单文件发布，使用者无需安装 .NET；首次运行会将打包的原生运行时组件解压到系统管理的临时位置。源码、配置和构建产物不需要一同分发。

技术：C# / WinForms、Windows 显示 API、`RegisterHotKey`、`NotifyIcon`，无第三方应用依赖。
